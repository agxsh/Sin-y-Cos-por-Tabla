# Sin-y-Cos-por-Tabla

BORRADOR DE OBJETIVO: 
- El objetivo del presente proyecto consiste en elaborar una tabla de 
    consulta capaz de almacenar los resultados de seno y coseno en un rango de 
    0 grados hasta 90 grados. Estos valores consultados se encuentran precargados 
    en la tabla para facilitar el uso al usuario y la incorporacion de una 
    mejor optimizacion en la nueva ISA planteada.
