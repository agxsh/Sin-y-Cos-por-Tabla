# Sin-y-Cos-por-Tabla

BORRADOR DE OBJETIVO: 
- El objetivo del presente proyecto consiste en elaborar una tabla de 
    consulta capaz de almacenar los resultados de seno y coseno en un rango de 
    0 grados hasta 90 grados. Estos valores consultados se encuentran precargados 
    en la tabla para facilitar el uso al usuario y la incorporacion de una 
    mejor optimizacion en la nueva ISA planteada.

Distribucion de carpetas:
    - Prototipo V1 (cambios hasta 27 de octubre):
        - Tabla.h: Funciones y valores escenciales
            - Valores PI para determinar cuadrante
            - 2 funciones de conversion
            - 1 funcion para inicializar valores en la tabla
            - 1 funcion de copia de valores para mantener originales
            - 1 funcion para mostrar en como queda el formato de la tabla en obj
            - 1 funcion de muestra para verificar unicamente los valores
            - 1 funcion para determinar cuadrante, referencia, y signo de sin/cos
